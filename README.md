## RSA  
### Основные формулы
c = t^e mod N //шифрование  
t = c^d mod N //дешифрование

### Проводим алгоритм
p = 683  
q = 167  
N = p * q = 683 * 167 = 114 061
f(N) = f(p * q) = (p-1)(q-1) = 166 * 682  
e - шифрующая экспонента или же открытый ключ, при чем НОД(f, e) = 1  
Подбираем e = 7  
d - ? Нужно найти такое d, чтобы d * e mod f(N) = 1 --> d * e + x * f = 1  
d * 7 + x * 114 061 = 1.  d = 32589, где x = -2.
